# Pre-launch checklist

1. Read **docs/YOUR_PART.md** (AdMob, package name, Studio build).
2. Replace test AdMob IDs in `ads_config.xml`, `Slots.kt`, and the manifest App ID.
3. Confirm logo in `branding/logo/logo.png` and regenerate if needed.
4. Keystore backed up; Play App Signing on when you publish.
5. GitHub Actions secrets if you use CI release builds.
6. Enable GitHub Pages from `/docs`.
7. Fill governing-law placeholder in `docs/terms.html`.
8. Two physical phones: Nearby send/receive once.
9. Privacy/Terms URLs match Play Console.

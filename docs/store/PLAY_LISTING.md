# Play listing (1.1)

Title: BQ Sqwad Share

Short description: Send files to nearby phones, iPhone browsers and computers. No account.

Full description:
BQ Sqwad Share moves photos, videos, music, documents, apps and other files without creating an account.

Share with Android phones nearby using discovery, a QR code or a 6-digit code. Share with iPhone, iPad, Mac, Windows, Linux or Chromebook on the same Wi-Fi through a secure link and PIN in the browser. Optional internet transfer by code is available when both sides can reach the network.

Pick only the files you want. Watch progress, pause and try again if a transfer stops. Received files can be sorted on the device. History, favorites and a storage cleaner stay on the phone.

BQ Sqwad Share is made by BQ Sqwad Technologies.

Keywords: nearby share, file transfer, offline, QR, Wi-Fi, iPhone, browser, no login, BQ Sqwad

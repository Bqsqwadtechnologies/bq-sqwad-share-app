# App Logo — Upload Here

Upload the larger app logo or wordmark as:

- `app-logo.png` — primary logo artwork
- `app-logo-mono.png` — optional single-colour version

Prefer a high-resolution PNG with a transparent background. Keep the logo's original proportions. This logo supports headers, splash/brand presentations, promotional artwork, and other places where the full logo is more suitable than the square app icon.

The square master app icon in `../app-icon/app-icon.png` remains the primary source for icon-based surfaces.

# BQ Sqwad Share app identity

Upload the one master app icon here as **app-icon.png** (square PNG, ideally 1024×1024 or larger, transparent background where appropriate).

This is the only master app artwork source. Run `python3 scripts/generate_branding.py` to generate the Android launcher densities, adaptive foreground/monochrome assets, notification mark, in-app `brand_logo.png`, and Play Store icon. Generated files must be committed to the repository after generation.
